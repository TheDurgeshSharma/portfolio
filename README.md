# Portfolio — Durgesh Kumar Sharma

## Run locally
    node server.js        # http://localhost:3000
    python -m http.server 3000

## Files
- index.html — the site
- photo.jpg — your portrait (add it next to index.html)
- Durgesh_Kumar_Sharma_QA_Automation_Resume.pdf — download link target

## Fill optional sections
Open index.html, find `var SITE=` near the end, and add items to
`achievements`, `testimonials` and `articles`. Empty lists stay hidden.

## Put it online (free)
GitHub Pages:
1. Create a repo (e.g. `portfolio`), upload index.html, photo.jpg and the PDF.
2. Settings > Pages > Deploy from branch `main` / root.
3. Your site: https://imdukush.github.io/portfolio/

Netlify: drag the folder onto https://app.netlify.com/drop.

## After it is live
- Add the link to your LinkedIn profile (Contact info > Website) and the Featured section.
- Add the link to the header of your resume PDF and your GitHub profile README.
